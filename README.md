# AI Shopping Assistant

An intelligent, conversational shopping agent built with LangChain, Groq LLMs, and Streamlit. It lets users search for products by text or image, filter by price/rating/organic status, and place orders — all through a natural chat interface.

Features

- Natural Language Search — Ask for products in plain English (e.g. *"organic honey under $15 with 4+ stars"*)
- Image-Based Search— Upload a product photo and the agent identifies it and finds similar items in the store
- Smart Filtering — Filter results by price, rating, and organic certification
- Rating Integration — Pulls live ratings from a reviews database for each candidate product
- One-Click Ordering — Confirms orders conversationally and saves them to the database
- Streamlit UI — Clean chat interface with a sidebar for image uploads

Project Structure

shopping-agent/
├── app.py                # Streamlit frontend — chat UI + image sidebar
├── shopping_agent.py     # LangChain agent — tools, LLM config, system prompt
├── reviews_api.py        # Reviews helper — queries ratings from store.db
├── setup_db.py           # DB initializer — creates tables and seeds sample data
├── store.db              # SQLite database (auto-generated by setup_db.py)
├── requirements.txt
└── .env                  # API keys (not committed — see setup below)

How It Works

User Input (text or image)
        │
        ▼
  Streamlit (app.py)
        │
        ▼
  LangChain Agent (shopping_agent.py)
   ├── describe_product_image()  ← vision LLM (Llama 4 Scout via Groq)
   ├── search_products()         ← keyword + filter SQL query on store.db
   ├── get_rating()              ← reads reviews table via reviews_api.py
   └── checkout()                ← inserts order into orders table
        │
        ▼
    store.db (SQLite)
   ├── products  (32 items across 8 categories)
   ├── reviews   (customer ratings)
   └── orders    (placed orders)

 Getting Started

1. Clone the repository


git clone https://github.com/YOUR_USERNAME/shopping-agent.git
cd shopping-agent

 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate      # macOS/Linux
venv\Scripts\activate         # Windows
```
 3. Install dependencies

```bash
pip install -r requirements.txt
```
 4. Set up environment variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Get a free API key at [console.groq.com](https://console.groq.com).
 5. Initialize the database

```bash
python setup_db.py
```

This creates `store.db` with 32 sample products across 8 categories and pre-seeded customer reviews.
 6. Run the app

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

 Example Prompts

| What you type | What the agent does |
|---|---|
| `I want organic honey under $15` | Searches, filters by price & organic, shows rated results |
| `Show me nuts with 4.5+ stars` | Searches nuts, calls get_rating, filters and lists |
| `Order the first one` | Calls checkout with the correct product ID |
| *(upload honey jar photo)* | Identifies product via vision LLM, finds similar items |



 Database Schema

products
sql
id, name, category, price, description, is_organic


reviews
sql
id, product_id, rating, reviewer_name, review_text


orders
sql
id, product_id, product_name, price, ordered_at
